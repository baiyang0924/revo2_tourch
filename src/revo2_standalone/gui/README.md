# 电脑直连数据手套 GUI：摄像头手势实时驱动 Revo2 灵巧手

笔记本摄像头识别右手姿态 → 实时映射到强脑 Revo2 触觉版灵巧手（6 个电机）。
**手经 USB 转 485/Modbus 直接连在本机**，由本机程序直接下发动作、读回位置 / 电流 / 触觉，
全程**不经过机器人**。适合桌面调试、示教录动作、力矩实验。

> **两条路线，不要混**：
> - **电脑直连（本目录）**——手直接插在本机 USB 上（RS485/Modbus，右手默认 COM+ID 127）；
> - **机器人端中转**——本机发目标值 → 机器人机载电脑 → CANFD → 手（真机演示用）。
>   代码在同模块的 `tools/revo2_hand_teleop_client.py`（本机端）+
>   `tools/revo2_hand_teleop_server.py`（机器人侧）。

运行环境：Windows 10 / 11（需要 COM 串口与摄像头），Python 3.10+。

## 〇、一键启动（推荐，双击就行）

双击 `start_gui.bat`，它会依次自动做四件事，每步都有中文提示：

1. 检查 Python 版本
2. 检查依赖，缺什么自动装什么（第一次运行要等几分钟；失败会给出手动安装命令）
3. 检查手部识别模型 `hand_landmarker.task`，没有就自动下载（失败会给出手动下载链接）
4. 打开图形界面

失败不会闪退，会停在报错页说明原因和解决办法，看完按回车关窗口，处理完重试。

**唯一的准备动作**：关掉强脑「上位机」软件——串口不能同时被两个程序占用，
否则「连接」会失败。

手动方式（知道自己在干嘛时用）：

```bash
python revo2_touch_gui.py              # 右手（默认），自动探测串口
python revo2_touch_gui.py --dry-run    # 只跑识别和界面，不连手（先调参用）
python revo2_touch_gui.py --id 126     # 左手
```

## 一、界面

窗口分四块：

1. **① 连接** —— 选串口、填设备 ID（右手 127 / 左手 126）、波特率（默认 460800），点「连接」。
   连上后显示左右手 / 固件 / 触觉厂商 / 单位模式，并自动检查单位口径（见下文自查）。
2. **② 力矩显示** —— 六个电机的实时电流（单位 mA，负值 = 反方向）。电流 ≈ 力矩（τ ≈ Kt·I），
   这是这双手能读到的、最接近「关节力矩」的量，读协议寄存器 2012–2017。
   下方一行是**触觉法向力**（寄存器 4200–4214，单位 N，量程 0–25 N；
   官方语义：寄存器值 ÷ 100 = 牛顿）。
3. **③ 力矩调节** —— 六个「保护电流」滑块（100–1500 mA，默认 500）。
   保护电流是这双手的力矩上限参数（寄存器 930–935）：调大 → 单指能出更大的力；
   调小 → 抓得轻、更安全。**松手即写入、立即生效**，跟随过程中随时可调。
4. **④ 量程标定** —— 各人手型不同，可采一次「张开 / 闭合」建立自己的量程，存到 `teleop_calib.json`。
   **「采「张开」」用自然张开姿势**（手指伸直、拇指自然外展，平时演示怎么比就怎么采，**不用伸到最开**）；
   「采「闭合」」握拳、拇指压向掌心。注意：「拇指掌」的**默认量程已按「自然张开 = 0 点」校准过**
   （-15°→张开、+20°→收拢），不做标定也能用；标定只是把 0 点换成实测值。

## 二、怎么跑

```bash
# 1) 装依赖（本目录的 requirements.txt 已锁定版本）
pip install -r requirements.txt

# 2) 模型文件：一键启动会自动下载到本目录
#    手动下载链接（约 8 MB）：
#    https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task

# 3) 关掉强脑「上位机」软件（否则串口被占用）

# 4) 运行
python revo2_touch_gui.py              # 右手，自动探测串口
python revo2_touch_gui.py --dry-run    # 只跑识别和界面，不连手（先调参用）
python revo2_touch_gui.py --id 126     # 左手
python revo2_touch_gui.py --model <路径>\hand_landmarker.task
```

**操作顺序**：连接 → （可选）标定 → 开始跟随 → 手在摄像头前比划 → 界面看电流和力 →
需要调力度就拖滑块 → 结束前点「全部张开」或「急停」。

**「手不动」先自查三步**：

1. 看画面底部横幅：`NOT FOLLOWING` = 还没开始跟随 —— 右侧面板点「**开始跟随**」
   （红色常驻状态条也会提示）。点完变绿 `FOLLOWING` 才会发指令。
2. 右侧面板内容比窗口高，**面板可以滚动**（鼠标滚轮或右侧滚动条），「开始跟随」按钮在最下面。
3. 「开始跟随」只在**手在动**时下发（静止 2.5 秒自动停发卸力，再动会自动恢复）——降温设计，不是坏了。

**「只有个别手指动 / 手指乱跟」**（2026-10-08 已修复）——两个协议口径问题：

- 位置下发寄存器 `1010` 必须按官方 **12 个寄存器**写：`位置,时间, 位置,时间…` 逐指交错。
  按「6 个位置 + 1 个时间」共 7 个写会整块错位：中指只收到"时长"、无名指/小指从未被写入，
  表现就是「只有部分手指动」。已修正并真机复验（六个电机全部到位）。
- 单位模式寄存器 `937` 必须是 **1 = 物理单位（度）**；连上手后程序会**自动检查并切换**，
  连接信息里会显示「单位:物理(度)」。

**「拇指方向不对：张开时反而往掌心收」**（2026-10-08 已修复）：

- 涉及关节：**拇指掌（拇指 Aux 对掌关节）**，映射链 = 摄像头「拇指掌」通道 →
  `DEFAULT_RANGE[1]` 量程 → ×`ANGLE_LIMITS[1]=89°` → 寄存器 1012。
- 原因：旧默认量程把 0 点定在「最大外伸 −55°」，而自然张开手拇指只到 ≈−15°，
  于是自然张开被算成 0.58 → 手被转到约 51°，看起来就是往掌心收。
- 修正：默认量程改为 **(−15°, +20°)**（自然张开 = 向外张开 0°，压向掌心 = 收拢 89°），
  并给拇指通道加 0.10 软死区（张开状态稳定不抖）。

**性能**：识别按 1280×720 @ 约 30 fps 处理（画面显示缩到 960 宽，界面不拖后腿）；
参数变化大时自适应加速平滑（减延迟），静止时强平滑（抗抖动）；
下发 30 Hz、每指执行时长 80 ms。实测整体跟随延迟约 0.1–0.2 s。

**逐指体检**（怀疑某根手指不响应时用）：

```bash
python hand_check.py --port COM24 --id 127                             # 只读：读出全部状态与配置
python hand_check.py --port COM24 --id 127 --wiggle --i-know-its-real  # 逐指 +15° 验证（手指会动！）
```

## 三、安全说明

- 写动作走 `revo2_modbus.set_angles`，内置角度限位（拇指 59°/89°，四指 81°）和 `allow_write` 门禁。
- 启动后默认「未使能」，点「开始跟随」才真正下发运动指令。
- 「急停」只停止下发、不额外发指令，手停在当前位。
- 「全部张开」是显式的 0° 一次性指令。
- 手静止超过 2.5 秒会自动停止下发，让电机卸力降温。

## 四、两个要如实说明的点

1. **「力矩」的取值**：这双手没有直接的关节力矩传感器。界面上的「力矩」用电机电流（mA）代理，
   电流与力矩近似成正比。指尖的真实受力来自触觉传感器（电容式）：界面已按官方语义解析出
   **法向力（N = 寄存器值 ÷ 100，量程 0–25 N）**，切向力/方向角/接近值暂不展示。
   触觉数据的开关是寄存器 4000–4004；若读数全为 0，先确认开关是否打开、指尖是否真的接触到东西。
2. **控制通道**：程序走 Modbus 的「位置 + 时间」模式（不是电流闭环），
   所以滑块调的是**保护电流上限**（力矩上限），不是力矩闭环给定值。
   真正的「恒力抓取」需要以 `read_currents` / 触觉力（法向力已可读）做外环，属后续工作。

| 文件 | 作用 |
|---|---|
| `start_gui.bat` | **一键启动入口（双击这个）** |
