此目录用于存放文档插图（接线照片、界面截图、尺寸图）。

命名规范：`<文档编号>-<序号>-<内容>.<扩展名>`

- 文档编号：对应 `docs/` 下的编号（`01` / `02` / …）
- 序号：该文档内的插图顺序，两位数字
- 内容：英文短横线命名（仓库内文件名统一用 ASCII，见 `docs/02` 第 5.2 节）
- 例：`01-01-485-adapter-box.jpg`、`01-02-485-terminal-board.jpg`

## 注意

- 图片请先压缩（单张建议 < 500 KB），避免仓库膨胀
- 不要放官方 PDF 或 7z 安装包，那些走公司文件服务器
- 涉及**序列号、订单号、屏幕上的公司内网信息**的照片，先打码或裁掉再入库
