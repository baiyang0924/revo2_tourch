# 17 · 实时遥控仿真窗口

> 背景：此前仿真交付形式为「跑完一条命令 → 产出一段 gif」，属离线录像。
> 该形式无法在演示现场即时查看动作、也无法交互调整角度。
> 本文记录把这些能力改为**实时交互窗口**的实现与实测结果。
> 记录时间：2026-09-23 17:00~17:30，全部结果在 Windows 本机实测。

---

## 0. 结论摘要

| 项 | 结果 |
|---|---|
| 运行形态 | 离线录像 → **实时 3D 窗口**（`mujoco.viewer` 被动模式 + 主线程步进） |
| 交互方式 | 命令行指令 + 键盘按键（两路并存） |
| 一条命令完成的动作 | 抬臂 → 伸手 → 下降 → 锁瓶握紧 → 抬起（17 s 实测完成） |
| 数值验收 | 瓶 0.860 m → **1.002 m**（抬升 **142 mm**），手-瓶距离 **0 mm**（已锁定） |
| 离线渲染依赖 | 实时窗口**不需要** `MUJOCO_GL`（仅离线出图需要），本机 Windows 直接可用 |
| 已排除的 3 个失效环节 | 见 §3，均为实测定位，非推断 |

**一句话**：同一套模型与物理，改为逐帧绘制并开放关节指令，实现了可现场演示、可交互操作的仿真形态。

## 1. 交付物

| 文件 | 作用 |
|---|---|
| `tools/elf3rig.py` | 控制与运动学小库：`Rig`（PD + 重力前馈、基座钉固、瓶子锁定）、`ArmIK`（阻尼最小二乘逆运动学，支持双轴向约束） |
| `tools/teleop_arm_hand.py` | 实时遥控主程序（窗口 + 物理步进 + 命令线程 + 键盘回调） |

运行方式：

```bash
# Windows（本机已建好的仿真环境）
D:\sim\.venv\Scripts\python.exe dexterous-hand\tools\teleop_arm_hand.py ^
    --model D:\sim\elf3_revo2_sim\scene_bottle.xml
```

`teleop_arm_hand.py` 默认按 `D:\sim` 布局定位模型；换机器时用 `--model` 指定场景文件即可。

## 2. 控制接口

### 2.1 命令行指令

在启动终端中直接输入，回车生效。角度单位统一为**度**。

| 指令 | 含义 |
|---|---|
| `arm <0~175>` | 抬起手臂的角度（0 = 自然下垂，越大越高） |
| `sy` / `sx` / `sz` `<deg>` | 肩关节前摆 / 侧摆 / 横扫（`sx` 负值为抬起） |
| `elbow <deg>` | 手肘屈伸（限位 −55~95°） |
| `wx` / `wy` / `wz` `<deg>` | 腕部三轴 |
| `hand <0~100>` | 握拳百分比（0 = 全开，100 = 全握） |
| `finger <deg>` | 六指统一给定角度 |
| `reach` / `down` / `lift` | 伸至瓶上方 / 下降至抓取高度 / 抬起 |
| `grasp` / `open` | 握紧抓瓶 / 松手 |
| `auto` | 连续执行完整流程 |
| `home` / `status` / `help` / `q` | 回起始位 / 打印当前状态 / 指令表 / 退出 |

角度输入在写入前按模型关节限位**逐项钳位**，越界指令会被截断而非静默丢弃。

### 2.2 键盘按键

按键回调绑定在窗口上，需先使窗口获得焦点。步长固定 5°（握拳 10%）。

| 按键 | 作用 |
|---|---|
| ↑ / ↓ | 抬臂 ±5° |
| ← / → | 手臂横扫 ±5° |
| W / S | 手肘 ±5° |
| `[` / `]` | 握拳 ∓10% |
| G / O / R | 握紧 / 张开 / 回起始位 |
| 1 / 2 / 3 | 伸至瓶上方 / 下降 / 抬起 |
| A / H | 完整流程 / 帮助 |

## 3. 实测定位的三个失效环节

本节三条问题均在一次自动流程中依次暴露，逐条定位并修复；附现象与判据，便于复现排查。

### 3.1 起始位落在瓶体范围内

**现象**：流程启动后瓶子被弹开约 1.1 m，滚落地面。

**定位**：以零位关节角 `home_arm_q()` 正运动学求出起始手根位置 `[0.276, -0.231, 0.838]`，
与瓶心 `[0.263, -0.215, 0.860]` 距离仅 **30 mm**，而瓶半径 **32.5 mm** ——
起始即处于与瓶子相交的状态，手臂首次运动即产生巨大排斥力。

**修正**：起始位改为逆运动学解出的工作区外位姿
（`HOME_HAND_TARGET = [-0.04, -0.06, 0.98]`，距瓶 **361 mm**）。
零位关节角仅作为逆运动学的迭代初值，不再作为起始状态。

### 3.2 手根到位但手指朝向错误

**现象**：手根位置误差收敛到 **4 mm**，但 `grasp` 判定不过（手-瓶 **155 mm**）。

**定位**：逆运动学仅约束「手根 Y 轴竖直」以保持瓶轴竖直，属 **5 自由度**约束，
绕瓶轴的滚转自由 —— 手根位置正确，手指伸出方向（手根 Z 轴）却可能背离瓶子。

**修正**：`ArmIK` 增加 `axis_z` 约束项，将手根 Z 轴指向「手根 → 瓶心」方向在水平面的投影。
增加约束后手根到位即手指对准，抓取判定通过。

### 3.3 张开的手指下降时将瓶子弹飞

**现象**：下降过程中瓶子被弹开 **800 mm**。

**定位**：已知官方 Revo2 碰撞网格与 Ø65 mm 瓶体互相嵌入约 40 mm；
手指张开时同样嵌入，接触求解器对深嵌入给出巨大排斥力。

**修正**：运行时改写碰撞分组，使手与瓶体**互不碰撞**，瓶体与桌面/地面仍正常碰撞：

| 几何组 | `contype` / `conaffinity` | 效果 |
|---|---|---|
| 瓶体 | `2` / `2` | 瓶 × 手不碰；瓶 × 桌碰 |
| 桌面、地面 | `1` / `3` | 承接瓶体 |
| 机器人本体 | `1` / `1` | 手 × 桌碰 |

抓取改由「手指合拢瞬间将瓶锁定在手根坐标系固定位置」实现，
与离线 demo 的刚性夹持策略一致；两者在数值上互相印证。

## 4. 其它实现要点

**外环补偿须限幅并控制重解频率。** 纯 PD 力矩无重力补偿，稳态存在 50~110 mm 下垂。
补偿逻辑若每 0.1 s 以「当前实际关节角」为迭代初值重解，会因误差累积把腕关节推至限位
（实测 `wrist_x` 顶到 −165°）。改为：离线逐段规划轨迹（每段以上一段的解为初值）
→ 按时长播放 → 播放结束后再启动补偿，且补偿量**限幅 ±60 mm**、间隔 **0.5 s**、
迭代初值取**轨迹末端解**而非当前实测角。

**相机方位角沿用 `docs/15` 的结论。** 模型内机器人朝 **+x**、身体右侧为 **−y**。
实测 315°（右前方）与 300° 时，手中的瓶子被躯干或手掌遮挡；
**270°（正右侧）**配合 `lookat = [0.16, -0.22, 0.95]`、`distance = 1.9`、`elevation = 6°`
可完整呈现瓶子离桌过程。
